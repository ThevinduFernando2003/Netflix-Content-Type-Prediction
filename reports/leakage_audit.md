# Leakage audit

Generated by `scripts/leakage_audit.py` on the full cleaned catalogue.
Normalised mutual information uses `normalized_mutual_info_score` (arithmetic mean).
Cramer's V is computed on the same discrete version of the feature (quantile bins for numerics).
Logistic accuracy and ROC-AUC are **5-fold out-of-fold** scores of a one-column model.
The decision-stump accuracy is in-sample, because a depth-1 tree is the association diagnostic.
A single feature with ROC-AUC above about 0.97 is treated as a leak.

## Verdicts

### Banned

- `duration` raw string, logistic ROC-AUC 1.0000. `90 min` is a movie and `2 Seasons` is a TV show. The string is the label.
- `duration_unit`, logistic ROC-AUC 1.0000. This is the same fact, parsed. The leaky baseline is the only model allowed to use it, and that model is not served.
- `duration_minutes` (AUC 1.0000) and `duration_seasons` (AUC 1.0000). Which of the two is non-null is the label. The numeric audit keeps a missingness indicator so imputation cannot hide that.
- `duration_minutes_is_null`, AUC 1.0000. A missingness flag that restates the unit.
- Banned TV-format genre tokens, flag AUC 1.0000. Names such as `TV Dramas`, `Docuseries`, and `International TV Shows` are catalogue labels, not content. The honest model receives `n_genres` only.

### Quarantine decisions

- `rating` logistic ROC-AUC is 0.6387: **ALLOWED after quarantine**. `TV-Y`, `TV-Y7`, `TV-Y7-FV`, `TV-G`, `NR`, and `UR` skew toward TV, while `TV-MA` and `TV-14` appear on both classes. The 0.97 single-feature line is the ban threshold.
- `has_director` logistic ROC-AUC is 0.8960. BANNED. Single-feature accuracy is 0.9520 and Cramer's V is 0.8853. ROC-AUC can sit under the 0.97 perfect-separator line because the feature is binary and the classes are unbalanced, but the decision rule is still a catalogue-missingness detector: series usually have no director credit and films usually do. `features.use_has_director` is false. This extract uses the placeholder `Not Given` for most series and almost no films. Keeping that placeholder as a token would be the second-order leak the spec warns about, so cleaning maps it to missing and the boolean is then judged on its own AUC.

### Allowed, with the ablation

- Title text, including format words. The boolean `title_has_format_word` has AUC 0.5007. The no-TV-vocabulary track strips a fixed 20-word stoplist before TF-IDF so the reader can see how much of the score was the word `series` or `movie`. This extract has no synopsis column, so that ablation runs on the title.
- `n_genres` AUC 0.5417. The count is kept when it is far from a separator. The names are not used either way.
- `primary_country` AUC 0.6977, `release_year` AUC 0.3522, `years_to_platform` AUC 0.6154.
- `description_word_count` AUC 0.4998 and `n_cast` AUC 0.4998. On this extract both columns were absent from the Excel file, so the features are constant and are not passed to the honest model. A file that actually contains them will pick them up.

### What the honest model is allowed to see

`title` (TF-IDF), `primary_country`, `rating`, `release_year`, `year_added`, `month_added`, `years_to_platform`, `n_genres`, `n_countries`, `title_word_count`. Nothing derived from `duration`. No genre name.
